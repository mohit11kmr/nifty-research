# Browser E2E Skill

Use this skill when verifying web application user interfaces, dashboards, login flows, and frontend interactions.

## Browser Testing Workflow

1. **Verify Server & Endpoint**: Ensure the local or staging web server (e.g. `http://127.0.0.1:8766/`) is running and responding to HTTP requests.
2. **Launch Playwright Automation**: Use Playwright MCP or headless browser automation to navigate to target pages.
3. **Validate UI Elements**:
   - Inspect page titles, headers, navigation bars, and buttons.
   - Test form inputs, buttons, modals, and dynamic data tables.
4. **Test Dynamic States & Error Handling**:
   - Verify loading spinners, dynamic charts, and error alert rendering.
   - Capture screenshots or DOM snapshots for visual verification.
5. **Report Findings**: Document verified flows, visual state changes, and any console/network errors.
